# Meu Portfólio - Murilo Turini

## 📋 Descrição

Este é um portfólio pessoal desenvolvido em HTML e CSS, criado para apresentar informações sobre Murilo Turini, um estudante cursando Análise e Desenvolvimento de Sistemas (ADS) com interesse em programação e desenvolvimento web.

## 🎯 Funcionalidade

O portfólio apresenta:

- **Apresentação Pessoal**: Foto de perfil circular e breve descrição sobre o desenvolvedor
- **Informações de Contato**: Links diretos para os perfis do LinkedIn e GitHub
- **Design Responsivo**: Layout limpo e centralizado com estilo moderno

## 📁 Estrutura de Arquivos

```
meuPortifolio/
├── index.html          # Arquivo principal com conteúdo HTML
├── style.css          # Estilos e design da página
├── README.md          # Este arquivo
└── img/               # Pasta com imagens
    ├── foto minha.jpg # Foto de perfil
    ├── linkedin.png   # Ícone do LinkedIn
    └── github.svg     # Ícone do GitHub
```

## 🎨 Características de Design

- **Paleta de Cores**: Tons de azul (#6b83a3, #8b9af0) com fundo branco
- **Layout Centralizado**: Máximo de 400px de largura para melhor visualização
- **Bordas Arredondadas**: Elementos com border-radius para design moderno
- **Sombra Sutil**: Efeito de profundidade na caixa principal
- **Imagens Circulares**: Foto e ícones em formato circular
